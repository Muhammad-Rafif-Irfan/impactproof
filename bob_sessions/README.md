# IBM Bob session evidence

Save actual screenshots of the corresponding IBM Bob IDE task session summaries in this directory. Use this naming convention:

```text
<team>_task01_<description>_summary.png
<team>_task02_<description>_summary.png
...
```

Each PNG must be a real screenshot captured from the matching Bob IDE session summary. Do not add generated, reconstructed, or placeholder screenshots. The participant captures these images during the final Bob rehearsal.
